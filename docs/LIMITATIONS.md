# Intended use and limitations

- This repository provides research code, not a validated diagnostic or attribution tool.
- Hard-coded cohort assumptions in exact-source scripts may prevent general use without adaptation.
- Small sample sizes, linked variants, uneven missingness and mixed infections can alter genetic differentiation estimates.
- Site filtering affects the population of SNPs to which any estimate applies.
- Nested cross-validation does not substitute for an independently collected validation cohort.
- Model performance may reflect metadata, population structure or laboratory effects instead of portable geographic signals.
- Code and statistical routines are distributed without primary genomic data and without a claim of analytic, clinical or operational validation.

Any publication should transparently report negative results, abstentions, modelling changes, assumptions and the number of informative loci.
