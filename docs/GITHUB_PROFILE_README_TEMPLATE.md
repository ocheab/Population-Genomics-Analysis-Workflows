# Research Software & Reproducible Analysis

I develop and document reproducible computational workflows for biological data analysis using **R** and **Python**.

My software interests include genomic data quality control, population genetics, variant interpretation, statistical modelling, uncertainty quantification, and publication-quality data visualisation.

Repositories on this profile may provide reusable research code, software documentation, and synthetic demonstrations. **Availability of source code does not imply public release of associated study datasets or unpublished research findings.**

Software repositories include descriptions of their input requirements, methods, limitations, and reproducibility considerations.

*This is an optional generic GitHub profile template; it is not linked to any specific research result.*
